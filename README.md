# QQ 交换广场 · H5 交互 Demo

> QQ 关系链场景下的以物换物破冰功能原型，参考「星换万物」+ 社交线选题设计。

## 🎯 产品定位

在 QQ 关系链下打造轻量级的物物交换社区，让用户通过闲置物品建立自然社交连接。核心场景：**发现好物 → 打招呼换物 → 建立朋友关系**。

## 📱 五大页面

| 页面 | 说明 |
|---|---|
| **交换广场（列表页）** | 双层标签架构：一级 tab（推荐/关注/最新/最热）+ 二级品类横滚（数码/书籍/潮玩等 12 类）+ 高级筛选面板 |
| **详情页** | 换友信息、物品图集、想要 / 提供、互动按钮 |
| **发布器** | 极简分组结构（我想要 / 可以提供 / 展示所在地），支持文字/语音/图片/品类标签/AI 润色/草稿箱 |
| **我的页面** | 收藏 / 点赞 / 发布三个 tab |
| **聊天 AIO** | 换友对话页 |

## ✨ 功能亮点

- **草稿箱**：完整闭环（半屏 sheet 列表 + 图片/提供/想要/头像/昵称/发布时间 + 左滑删除 + 未保存离开拦截）
- **智能品类推荐**：用户输入「AirPods」→ 自动亮起「数码」标签（脉冲动画）
- **AI 润色**：字段级触发，一键优化文案
- **iOS 原生 ActionSheet**：退出确认走系统级三段式菜单
- **筛选面板**：排序 / 时间 / 距离 / 性别 / 年龄五组多维筛选

## 🛠 技术栈

- 单文件 HTML（HTML/CSS/JS 一体，无构建）
- iPhone 尺寸容器仿真
- QQ 视觉体系（`#12B7F5` 主色 + 浅蓝底胶囊按钮）
- 纯前端交互 Mock（数据为示例数据）

## 📐 设计规范

- 色板：QQ 蓝 `#12B7F5` / 深蓝 `#0091D5`
- 圆角：卡片 14-16px、按钮 15-16px
- 字重：主标题 700、次标题 600、正文 500、辅助 400
- 遵循 iOS Human Interface Guidelines
